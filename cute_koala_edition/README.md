
# Cute Koala Edition Game

This is a fun and educational game featuring Koko the Koala.

## How to Run

To run the game, use the following command:

```bash
cd /workspace/curio-critters/cute_koala_edition
python3 -m http.server 53465 --bind 0.0.0.0
```

Then open your browser and go to: [http://localhost:53465/](http://localhost:53465/)

## Game Features

- Interactive koala adventure
- Quest tracking system
- Skill development
- Story-driven gameplay
